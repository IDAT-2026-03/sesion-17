TEMA 1

Box-Sizing: ¿Cuánto mide realmente tu caja?

content-box vs border-box

En CSS, si defines width: 200px, ¿el elemento medirá 200px en pantalla? ¡Por defecto NO! La propiedad box-sizing define cómo se calcula el tamaño físico:

1. content-box (El comportamiento por defecto del navegador)

El ancho declarado es solo para el contenido. Si añades padding: 20px y border: 5px, el navegador se los suma hacia afuera.

Ancho Real = width (200) + padding (20+20) + border (5+5) = 250px ❌ ¡Engorda!
2. border-box (El estándar moderno de la industria)

El ancho declarado es el tamaño total definitivo. El relleno y el borde se absorben hacia adentro.

Ancho Real = EXACTAMENTE width (200px) ✔️ ¡Predecible y perfecto!
La Regla de Oro que Salva Vidas
/* El Reset que todo proyecto debe tener al inicio */
*, *::before, *::after {
box-sizing: border-box; /* ¡Garantiza medidas exactas! */
margin: 0;
padding: 0;
}
💡 ¿Por qué es vital antes de ver position? Porque si tus contenedores padres cambian de tamaño accidentalmente por culpa del padding, las coordenadas top, right y left de los elementos posicionados aterrizarán en lugares inesperados.

TEMA 2

Fusión: Static vs. Relative

Entendiendo el "Flujo Natural"

Para entender el posicionamiento, imagina una fila en el banco. Todo el mundo respeta su turno uno detrás de otro:

1. position: static (El valor por defecto de TODO en la web)

El elemento está en su lugar natural de la fila. Si intentas ponerle top: 20px o left: 50px, CSS lo ignorará por completo. Está pegado al suelo.

2. position: relative (El "desfase fantasma")

El elemento sigue guardando su lugar en la fila (sus vecinos no se mueven ni se enteran), pero se mueve visualmente respecto a donde debió haber nacido usando top, bottom, left o right.

⭐ Su superpoder secreto: Sirve como "ancla" para atrapar a los elementos absolute.
Sintaxis en CSS
/* Comportamiento Relative */
.caja-desplazada {
position: relative;
top: 15px; /* Baja 15px de su sitio original */
left: 20px; /* Se empuja 20px a la derecha */
}
💡 La regla de oro que debes recordar: relative nunca desacomoda a las cajas vecinas. Deja un "hueco invisible" en su posición original como si aún estuviera ahí.
Propiedades activas solo con position: top, right, bottom, left y z-index. W3C CSS Position Level 3

TEMA 3

Position Absolute: El Astronauta de la Web

La Pareja Inseparable: Relative + Absolute

Cuando a un elemento le pones position: absolute, ocurre algo radical: pierde la gravedad, despega de la fila y los demás elementos se cierran ocupando su lugar como si nunca hubiera existido.

⚠️ El gran error que todos cometen: Si declaras position: absolute; top: 0; right: 0; sin preparar a su padre, ¡el elemento volará hasta la esquina superior derecha de toda la ventana del navegador!
⚓ La solución: El contenedor "Ancla" (Relative) Para que el elemento absoluto flote dentro de una tarjeta, debes ponerle position: relative al contenedor padre. El padre se convierte en su jaula de contención.
El Combo que Usarás el 99% de Veces
/* 1. El Contenedor Padre (La Isla) */
.tarjeta-padre {
position: relative; /* <-- ¡ESTA ES LA CLAVE! */
}
/* 2. El Elemento Hijo (La Insignia Flotante) */
.badge-descuento {
position: absolute;
top: 10px;
right: 10px; /* Se pega a la esquina del PADRE */
}
Regla mnemotécnica: "Padre relativo, hijo absoluto". Comportamiento de Ancestros Contenedores

Fixed, Sticky y Taller de Capas (z-index)

position: fixed Se pega al marco de la ventana (viewport). Siempre inmóvil ante el scroll (ej: botón WhatsApp).
position: sticky Fluye normal hasta que choca con top: 0 y se congela en el techo al hacer scroll.
